# HW1 과제 안내문 — Java 기초와 배열

[레포지토리 안내](../../../README.ko.md) | [English](Assignment.md) | [한국어](Assignment.ko.md)

> **최종 수정일:** 2026-11-16

객체지향프로그래밍및실습의 1차 과제(HW#1)로, 4주차에 나왔다. 문제는 Q1\~Q10의 열 개이며, 각 문제를 읽고 프로그램을 작성한 뒤 결과 화면을 보고서에 붙인다. 이 레포지토리에는 Q1\~Q9의 풀이가 있다.

- **제출:** 문제와 결과 스크린샷을 채운 보고서(.docx)와 작성한 Java 코드(.java) 전체를 `HW1_YourID_Yourname.zip`으로 압축하여 정해진 시간까지 Blackboard에 제출한다. 조교가 실행했을 때 Java 코드가 깔끔하게 실행되어야 한다.
- **공통 규칙:** 모든 프로그램에 헤더 주석을 달고 표준 명명 규칙을 지켜야 하며, 지키지 않으면 각각 1점을 감점한다.
- **ChatGPT:** ChatGPT의 남용을 막기 위해 대부분의 문제에서 문제의 패턴 인식은 개발자의 몫으로 남겼다. 문제 제기, 패턴 인식, 요구사항 분할 능력은 ChatGPT가 아직 인간 개발자를 넘어서지 못하는 부분이며, 모두가 ChatGPT를 쓸 수 있는 지금은 누가 먼저 문제를 효율적으로 나누어 질문하는지도 중요하다. 이 과제에서는 ChatGPT를 적극적으로 활용하라.
- **표절:** 다른 학생의 코드를 복사한 것이 적발되면 F 학점을 받는다.

## Q1. 단어별 역순 출력

다음 예처럼 영어 문장을 입력받아 단어별로 거꾸로 출력하는 프로그램 `Q1.java`를 작성하라. 예에서 대소문자 규칙을 찾아 같은 결과를 내도록 주의하라.

대화 상자의 안내 문구와 입력:

```text
Please write any English sentence:
```


## Q2. 이름 인사와 학번 자릿수의 합

대화 상자로 이름과 학번을 입력받아 다음 예처럼 출력하는 `Q2.java`를 구현하라.

1. 입력한 이름과 학번은 자동으로 분리되어야 한다.
2. 학번의 각 자릿수는 반복문으로 누적 합산해야 한다. 예를 들어 학번이 "12345"이면 "1 + 2 + 3 + 4 + 5"의 결과를 출력한다.

대화 상자의 안내 문구와 입력:

```text
Enter your name & student ID (i.e. Minseok Seo / 12345678:
Minseok Seo / 12345678
```

출력:

```text
Hello OOP World! Minseok Seo
The sum of each number of your student number entered is 36
```

## Q10. ChatGPT로 만드는 메모장

ChatGPT를 사용하여 실행 가능한 Java 기반 메모장 프로그램을 구현하라. 설계와 동작 방식에는 제한이 없다. 다만 제목 표시줄에 본인의 학번과 이름이 나타나도록 해당 부분을 반드시 찾아 고쳐야 한다. 이 부분의 이론은 아직 배우지 않았지만, 이런 경험으로 반복해서 훈련할수록 기업과 연구소가 원하는 인재에 가까워진다.

ChatGPT를 써 본 적이 없으면 YouTube에서 "ChatGPT Java Notepad" 같은 키워드로 검색하면 많은 노하우를 찾을 수 있다. ChatGPT를 다루는 능력도 이 시대에는 개발자의 능력이다.
