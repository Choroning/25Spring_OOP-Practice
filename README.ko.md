## 📝 레포지토리 소개

- `Lecture-Notes/`에는 슬라이드 번호(`Lec01`\~`Lec15`)를 따른 강의 노트가 있습니다.
- `Coursework/`에는 단원별 Java 실습 코드(`Lab##`), 과제 풀이(`HW01`\~`HW03`), 텀 프로젝트가 있습니다.
- 모든 강의 노트는 영어(`.md`)와 한국어(`.ko.md`) 파일이 짝을 이룹니다.
- 모든 코드는 JDK로 컴파일하여 확인했습니다.

> **🤖 AI 에이전트 활용**
> 이 과목은 과제에서 ChatGPT 활용을 허용했습니다.
> [Claude Code](https://claude.ai/download)를 노트 정리와 번역, 레포지토리 정리에 활용했습니다.

### 과목 개요

Java로 객체 지향 프로그래밍의 핵심 개념과 기초를 배우는 전공선택 과목으로, 영어로 진행된다. 교수자와 조교, 수업 일정, 평가, 수업 운영 규정, 진도는 [강의 정보 문서](Course-Information.ko.md)에 정리했다.
